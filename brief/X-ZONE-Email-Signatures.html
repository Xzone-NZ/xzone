How to install

  1. Gmail: click Copy signature above, then Settings, See all settings, Signature, Create new, paste, Save changes.
  2. Outlook (new or web): Settings, Accounts, Signatures, New signature, paste, Save.
  3. Apple Mail: Mail, Settings, Signatures, add one, paste. Untick "Always match my default message font".
  4. Outlook classic (Windows): paste works, or use Copy HTML and import via a signature file if you prefer.
